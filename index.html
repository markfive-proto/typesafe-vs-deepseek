TypeSafe vs DeepSeek vs OpenAI

Same task, three engines, side by side — speed, tokens, cost, accuracy, and hallucination rate against known ground truth.

50 synthetic invoices, native PDF/XLSX (no OCR needed — text extracted directly via pdfplumber/openpyxl).

50 synthetic emails across 7 categories — select some, classify with all three engines.

Rerank a corpus by relevance to a query. TypeSafe asks all N relevance questions in one call (true intra-request parallelism); DeepSeek/gpt-5-nano each rank all N candidates in one generative pass.

Time to output = when that engine's own last response actually landed (its real, per-engine finish time — not a shared clock dominated by whichever engine is slowest). Sum latencies = if every one of that engine's calls had run one-after-another instead of concurrently — the gap between the two is the parallelism payoff. Hallucinated: TypeSafe's Choice only ever returns a value from the candidates/criteria it was given, so it's structurally grounded (always 0%). DeepSeek/OpenAI free-text-then-parse can invent a category outside the given list, an invoice number/total not present in the source text, or a candidate id in reranking that doesn't correspond to any real candidate — each counted here as a hallucination. Cost: TypeSafe Jev $42/Btok input (output free); DeepSeek-flash off-peak cache pricing; gpt-5-nano $0.05/$0.40 per Mtok in/out.
